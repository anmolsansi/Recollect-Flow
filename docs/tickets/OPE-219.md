# OPE-219 implementation and device gate

The backend URL/text/image/PDF/file/audio contracts, one-request Shortcut compatibility endpoint, secret-free Shortcut build sheet, durable offline queue/retry design, truthful status mapping and redacted device QA matrix are repository-complete. The endpoint performs private attachment validation/storage/finalization/linking server-side and returns stable queue actions.

Production Worker version `c0e78f89-d7a6-4416-a638-57693d256c03` and migration `0006` were deployed on 2026-07-28. Live authenticated text and PDF saves plus idempotent replays passed. Two secret-free Mac exports were also produced:

- `Save to Recollect (Template v1.1).shortcut`
- `Retry Recollect Item (Template v1.1).shortcut`

The exports are an online-save/manual-retry baseline. They do not yet implement the full durable iCloud queue described in the build sheet, and their file magic-variable behavior has not been proven on an iPhone. The physical-device gate below therefore remains required before closure.

Human gate:

- [ ] Install the secret-free template in Shortcuts.
- [ ] Add API URL and capture token on device without exporting them.
- [ ] Accept Share Sheet, iCloud Drive, Photos and Files permission prompts.
- [ ] Complete every row in `clients/ios-shortcut-device-qa.md` on the physical iPhone.
